---
name: Страницы Selenium
description: Используй при добавлении Page Object или общего компонента в Java UI-тестах по образцу Sprint_6.
---

1. Определи владельца элемента. Как в `MainPage` и `CreateOrderPage` из Sprint_6, держи поля и действия одной страницы вместе. Повторяющуюся шапку вынеси в компонент, как `HeaderComponent`.
2. Передавай `WebDriver` через конструктор. В базовом классе храни драйвер, `WebDriverWait` и общие операции. У каждого локатора должно быть имя по назначению элемента.
3. Перед вводом дождись видимости, перед кликом — кликабельности. После анимации дождись конечного состояния интерфейса. Например, активная вкладка и видимый заголовок раздела должны соответствовать друг другу.
4. Для последовательных действий на одной странице возвращай `this`, когда это упрощает сценарий. Метод чтения возвращает фактический текст, значение поля или признак видимости. Как `getFaqAnswerText`, он не задаёт ожидаемый ответ.
5. В проектах с Allure помечай публичные действия и чтение состояния через `@Step`. Не подменяй ожидания паузами или перехватом всех исключений.
